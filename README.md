# docker-Hail
Boutros Lab Docker image for Hail.

# Version
| Tool | Version |
|------|---------|
| Hail | 0.2.139 |
| Python | 3.10 |
| OpenJDK | 11 |

---

## Runtime Notes

- Includes `libnss-wrapper` so the container can run with arbitrary `uid:gid` mappings.
